# Credits

## Code
Monster Fights was built with [Three.js](https://threejs.org) (MIT license) and [Vite](https://vitejs.dev) (MIT license).

## Art
- Monster concept images and the roster board (`reference/`, `public/assets/`) were provided by the project owner.
- All 3D monsters, arenas, props and effects are procedural (built in code from Three.js primitives).

## Audio
All sound effects and the battle music are **synthesized in real time with the Web Audio API** (`src/audio/audio.js`).
No external sound or music files are used, so there is nothing to license.

## Fonts
- "Russo One" and "Rajdhani" from Google Fonts (SIL Open Font License 1.1), loaded from fonts.googleapis.com.
  The game falls back to system fonts if they cannot be loaded.
